# 🤖 Modelo Z 3025 – Proyecto React Interactivo

Proyecto práctico de desarrollo web con **React.js**, centrado en la presentación de un producto ficticio de última generación: el **Modelo Z 3025**, un cyborg diseñado para mostrar animaciones, interacciones y renderizado 3D en un entorno moderno, dinámico y 100% responsive.

🌐 [Ver sitio online](https://modeloz3025.netlify.app/)

---

## 🚀 Tecnologías utilizadas

- ⚛️ **React.js**
- ⚡ **Vite** – build rápido
- 🎨 **Tailwind CSS** – diseño adaptable
- 🎥 **GSAP (GreenSock)** – animaciones suaves
- 🧠 **Three.js** – motor 3D
- 🧱 **React Three Fiber** – bindings de React para Three.js
- 🧩 **React Three Drei** – helpers para escenas 3D

---

## 🎯 Funcionalidades destacadas

### 🎞️ Animaciones fluidas (GSAP)
- Transiciones y animaciones personalizadas en elementos clave de la UI.
- Experiencia visual moderna y envolvente.

### 🧊 Modelo 3D interactivo (Three.js)
- Renderizado 3D del cyborg "Modelo Z 3025" desde todos los ángulos.
- Cambio de color y tamaño del producto.

### 🎠 Carrusel animado (con GSAP)
- Carrusel de imágenes/videos diseñado desde cero con animaciones personalizadas.
- Navegación fluida e intuitiva.

### 📱 Responsive Design
- Adaptación completa a dispositivos móviles, tablets y desktop.
- Experiencia consistente sin importar la resolución.
